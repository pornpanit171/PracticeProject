# CISSP Practice Bank

ระบบฝึกทำข้อสอบแบบเว็บสองภาษา (ไทย/อังกฤษ) ทำงานเป็น static site ล้วน ไม่มีเซิร์ฟเวอร์
โฮสต์ฟรีบน GitHub Pages เก็บประวัติการทำข้อสอบลง Google Sheets

---

## ความสามารถ

**ก่อนเริ่มทำข้อสอบ**
- เลือกโหมด **Practice** (เฉลยพร้อมคำอธิบายทันทีหลังตอบแต่ละข้อ) หรือ **Exam** (ไม่มีคำใบ้ เก็บเฉลยทั้งหมดไว้ดูตอนจบ)
- เลือกลำดับข้อ **Sequential** หรือ **Random**
- เลือกโดเมนได้หลายโดเมนพร้อมกัน พร้อมป้ายบอกจำนวนข้อและความครบของคำแปลไทย — โดเมนที่ยังไม่มีโจทย์เลยจะไม่โผล่ในรายการ
- กำหนดจำนวนข้อเอง

**ระหว่างทำ**
- สลับภาษา **EN / TH** ได้ตลอดเวลา
- จับเวลาต่อข้อ แถบความคืบหน้า ตัวนับถูก/ผิด และปุ่มจบทันที
- ปักหมุดข้อที่อยากกลับมาดู
- คีย์ลัด `A`–`F` หรือ `1`–`6` เพื่อเลือกคำตอบ และ `Enter` เพื่อไปข้อถัดไป
- รองรับข้อที่ตอบได้หลายตัวเลือก
- ปิดหน้าไปแล้วกลับมาทำต่อจากเดิมได้

**หลังทำเสร็จ**
- สรุปคะแนนรวม แยกรายโดเมน และเวลาที่ใช้
- ดูเฉลยรายข้อ กรองเฉพาะข้อที่ผิดหรือที่ปักหมุดได้ — ข้อที่มีบทวิเคราะห์เพิ่มเติมจะโชว์กล่อง "เพิ่มเติม" ต่อท้ายเฉลย
- ทำใหม่เฉพาะข้อที่ตอบผิด
- ประวัติย้อนหลังข้ามเครื่องผ่าน Google Sheets พร้อมปุ่ม Export JSON

## เริ่มใช้งาน

### เปิดดูในเครื่อง

ต้องเปิดผ่าน http ไม่ใช่ดับเบิลคลิกไฟล์ เพราะระบบโหลดโจทย์ด้วย `fetch`
และระบบรหัสต้องการ secure context

```bash
python -m http.server 8765
```

แล้วเปิด <http://localhost:8765>

### เผยแพร่บน GitHub Pages

1. push โค้ดทั้งหมดขึ้น repo
2. ไปที่ **Settings → Pages**
3. Source เลือก **Deploy from a branch** → branch `main` → folder `/ (root)`
4. รอสักครู่ จะได้ URL หน้าตา `https://<user>.github.io/<repo>/`

### รหัสเข้าใช้งานเริ่มต้น

| รหัส | ชนิด |
|---|---|
| `CISSP-2026` | รหัสกลาง — ผ่านแล้วให้พิมพ์ชื่อเอง |
| `CISSP-GOTJI` | รหัสรายคน — ล็อกชื่อเป็น Gotji |

**เปลี่ยนรหัสก่อนใช้งานจริง:**

```bash
node tools/make-codes.mjs --reset --add "รหัสใหม่ของคุณ" --add "รหัสอีกอัน:ชื่อคน"
```

ถ้าไม่อยากมีประตูรหัสเลย ตั้ง `authRequired: false` ใน `assets/config.js`

## วิธีเพิ่มโจทย์

### ทางที่ 1 — Excel (เหมาะกับการนำเข้าทีละมาก)

1. โหลด [`tools/template.xlsx`](tools/template.xlsx) แล้วกรอกโจทย์แถวละหนึ่งข้อ
2. เปิด `tools/import.html` ในเว็บ ลากไฟล์มาวาง (หรือก๊อปจาก Excel มาวางตรง ๆ ก็ได้)
3. ดูรายการปัญหาที่ระบบขึ้นให้ แก้ใน Excel แล้ววางใหม่จนไม่มีข้อผิดพลาด
4. เลือกวิธีรวมกับของเดิม — **เพิ่มต่อท้าย** / **อัปเดตทับ** / **แทนที่ทั้งโดเมน**
5. กด **🚀 เผยแพร่ทั้งหมดขึ้นเว็บเลย** ให้ระบบ commit เข้า repo ให้อัตโนมัติ
   (ต้องตั้งค่าเพิ่มครั้งเดียวก่อน ดู [PUBLISH_SETUP.md](PUBLISH_SETUP.md))
   หรือถ้ายังไม่อยากตั้งค่า กดดาวน์โหลด JSON แล้วเอาไป commit ลง `data/` เองแบบเดิมก็ได้เสมอ

คอลัมน์ที่จำเป็นมีแค่ `domain`, `q_en`, `answer` ที่เหลือเว้นว่างได้
เว้น `id` ว่างไว้ ระบบจะรันเลขต่อจากของเดิมให้เอง
คำอธิบายทุกคอลัมน์อยู่ในชีต README ของเทมเพลต

มีคอลัมน์ `insight_en` / `insight_th` สำหรับใส่บทวิเคราะห์เชิงลึกเพิ่มเติมนอกเหนือจากคำอธิบายหลัก (`explain_*`)
ไม่บังคับ และปกติกรอกแค่ `insight_th` อย่างเดียวก็พอ — ระบบจะโชว์ให้ทั้งโหมด EN และ TH โดยอัตโนมัติ
กด `Alt+Enter` ในเซลล์ Excel เพื่อขึ้นบรรทัดใหม่ได้ ระบบจะคงการขึ้นบรรทัดนั้นไว้ตอนแสดงผล

### ทางที่ 2 — แก้ทีละข้อ

เปิด `tools/editor.html` เลือกโดเมน คลิกข้อที่ต้องการ แก้แล้วกดบันทึก
จากนั้นกดดาวน์โหลดไฟล์โดเมนนั้นไป commit

### ทางที่ 3 — แก้ JSON ตรง ๆ

แก้ไฟล์ใน `data/` บนหน้าเว็บ GitHub ได้เลย (กด `.` บนหน้า repo เพื่อเปิด github.dev)

### ตรวจก่อน commit เสมอ

```bash
node tools/validate.mjs
```

GitHub Action จะรันตัวเดียวกันนี้ให้อัตโนมัติทุก push ที่แตะโฟลเดอร์ `data/`
ถ้ามี id ซ้ำ เฉลยชี้ไปตัวเลือกที่ไม่มีอยู่ หรือ JSON พัง จะเห็นกากบาทแดงทันที

### รูปแบบข้อมูลโจทย์

```jsonc
{
  "id": "d1-0001",              // ห้ามซ้ำทั้งคลัง ใช้ผูกกับประวัติการทำข้อสอบ
  "type": "single",             // single | multi
  "q":  { "en": "...", "th": "..." },
  "choices": [
    { "k": "A", "en": "...", "th": "..." },
    { "k": "B", "en": "...", "th": "..." }
  ],
  "answer": ["B"],              // เป็น array เสมอ หลายตัวได้เมื่อ type = multi
  "explain": { "en": "...", "th": "..." },
  "insight": { "en": "", "th": "..." },  // ไม่บังคับ — บทวิเคราะห์เชิงลึกเพิ่มเติม แสดงต่อท้ายกล่องเฉลย
  "tags": ["risk-management"],
  "ref": "OSG ch.1"
}
```

ฟิลด์ `th` เว้นว่างได้ทุกที่ ระบบจะแสดงภาษาอังกฤษแทนแล้วนับเข้าป้าย `TH x/y` ในหน้าเลือกโดเมน
`insight` ไม่มีก็ได้ทั้งฟิลด์ — ข้อที่ไม่มีจะไม่ขึ้นกล่อง "เพิ่มเติม" เลย ไม่ใช่กล่องว่าง

## ประวัติการทำข้อสอบ

เก็บบน Google Sheets — ตั้งค่าครั้งเดียวโดยเจ้าของระบบ ดูขั้นตอนใน [SHEETS_SETUP.md](SHEETS_SETUP.md)

**คนที่มาทำข้อสอบไม่ต้องตั้งอะไรเลย** เปิดลิงก์ กรอกรหัส พิมพ์ชื่อ แล้วทำได้ทันที
หน้าประวัติจะกรองแสดงเฉพาะชื่อของตัวเอง ส่วนเจ้าของเปิดสเปรดชีตจะเห็นของทุกคนรวมกัน

ระหว่างทำข้อสอบ ผลจะถูกเก็บใน IndexedDB ก่อนเสมอ แล้วค่อยส่งขึ้นชีต
เน็ตหลุดจะขึ้นป้าย "รอซิงค์อยู่ N รายการ" พร้อมปุ่มลองใหม่ และซิงค์ให้อัตโนมัติรอบหน้าที่เปิดเว็บ
ถ้ายังไม่ได้ตั้งค่าชีตเลย ระบบจะทำงานในโหมดเก็บเฉพาะเครื่องพร้อมปุ่ม Export JSON

## ระบบรหัสเข้าใช้งาน

ตอนนี้ตั้งไว้ที่ **ระดับ 1** — ตรวจรหัสในเบราว์เซอร์โดยเทียบ PBKDF2 hash ใน `data/codes.json`

**ระดับ 1 กันคนที่บังเอิญเจอลิงก์ ไม่ได้กันคนที่ตั้งใจ**
ไฟล์โจทย์ใน `data/` เป็น JSON ธรรมดาที่เปิด URL ตรง ๆ ก็โหลดได้
ถ้าโจทย์ชุดนี้ยังไม่หวง ใช้ระดับ 1 ไปได้ยาว ๆ

### จัดการรหัส

```bash
node tools/make-codes.mjs --list                              # ดูรายการที่มี
node tools/make-codes.mjs --add "CISSP-2027"                  # เพิ่มรหัสกลาง
node tools/make-codes.mjs --add "CISSP-7K2M:สมชาย"            # เพิ่มรหัสรายคน
node tools/make-codes.mjs --add "TEMP-1" --expires 2026-12-31 # ตั้งวันหมดอายุ
node tools/make-codes.mjs --reset --add "รหัสใหม่"             # ล้างทั้งหมดแล้วเริ่มใหม่
```

ในระดับ 1 คอลัมน์ `max_uses` ยังบังคับใช้ไม่ได้ เพราะไม่มีฝั่งเซิร์ฟเวอร์คอยนับ
จะมีผลจริงเมื่ออัปเป็นระดับ 3

### อัปเกรดเป็นระดับ 3 ในภายหลัง

โค้ดวางโครงเผื่อไว้แล้ว การอัปเกรดคือแก้ config ไม่ใช่เขียนใหม่

1. ตั้งค่า Google Sheets ให้เสร็จก่อน ([SHEETS_SETUP.md](SHEETS_SETUP.md))
2. ใส่รหัสทั้งหมดลงในแท็บ `Codes` ของสเปรดชีต (คอลัมน์ชุดเดียวกับ `codes.json`)
3. เข้ารหัสไฟล์โจทย์ด้วยกุญแจจากแท็บ `Meta` → `encKey` แล้ว commit ทับ
4. แก้ `assets/config.js`:
   ```js
   authLevel: 3,
   encrypted: true,
   ```

หลังอัปเกรด ไฟล์ใน `data/` จะเปิดตรง ๆ ไม่ได้แล้ว และปิดรหัสของใครก็ได้ทันทีจากในชีต

**สิ่งที่อัปเกรดย้อนหลังไม่ได้:** โจทย์ที่เคยเผยแพร่เป็น JSON ธรรมดาไปแล้ว
ถ้าใครโหลดเก็บไว้ก็เก็บได้ถาวร การอัปเป็นระดับ 3 กันได้แค่คนใหม่เท่านั้น

## รหัส admin — จำกัดให้เฉพาะคนที่นำเข้า/แก้โจทย์ได้

`tools/import.html` และ `tools/editor.html` ถูกกั้นด้วยรหัส admin แยกต่างหากจากรหัสของคนทำข้อสอบโดยเจตนา
— รหัสที่ใช้เข้าทำข้อสอบ (`data/codes.json`) เปิดเครื่องมือเหล่านี้ไม่ได้

### ตั้งรหัส admin

```bash
node tools/make-codes.mjs --file admin-codes.json --reset --add "รหัส admin ของคุณ"
```

ใช้คำสั่งเดียวกับที่จัดการรหัสคนทำข้อสอบ ต่างกันแค่เติม `--file admin-codes.json`
รองรับ `--expires` / `--max` แบบเดียวกัน แต่ในระดับนี้ `--max` ยังไม่ถูกบังคับใช้จริง (เหตุผลเดียวกับรหัสระดับ 1 ด้านบน)

### เรื่องที่ควรรู้

- **ด่านนี้กันคนบังเอิญเจอ URL ไม่ได้กันคนที่ตั้งใจ** — เหมือนระบบรหัสของคนทำข้อสอบ เพราะเป็น static site
  ล้วน ไม่มีเซิร์ฟเวอร์ตรวจสิทธิ์จริง
- **ด่านที่แท้จริงที่ทำให้โจทย์ปลอมไปโผล่บนเว็บจริงไม่ได้คือสิทธิ์ push เข้า GitHub repo** —
  `tools/import.html` และ `tools/editor.html` ทำได้แค่ "ดาวน์โหลดไฟล์ JSON ลงเครื่อง" เท่านั้น
  ไม่มีทางเขียนกลับเข้า repo ได้เอง คนที่ไม่มีสิทธิ์ push จะทำให้โจทย์ใหม่ไปอยู่บนเว็บจริงไม่ได้อยู่ดี
  รหัส admin จึงเป็นแค่ชั้นกันไม่ให้คนนอกเปิดดู/generate ไฟล์เฉลยได้ง่าย ๆ ไม่ใช่การควบคุมสิทธิ์ระดับเซิร์ฟเวอร์
- **session ของ admin หายเมื่อปิดแท็บเสมอ** ไม่มีตัวเลือก "จำอุปกรณ์นี้ไว้" เหมือนฝั่งคนทำข้อสอบ
  เพราะหน้านี้เห็นเฉลยทั้งคลังพร้อมกัน ตั้งใจให้ต้องกรอกรหัสใหม่ทุกครั้งที่เปิดแท็บใหม่
- อัปเกรดเป็นระดับ 3 ได้ในอนาคตเช่นเดียวกับรหัสของคนทำข้อสอบ (ให้ Apps Script ตรวจแทน) แต่ยังไม่ได้ทำไว้ในเวอร์ชันนี้

## ตั้งค่าระบบ

แก้ทั้งหมดได้ที่ `assets/config.js`

| ค่า | ความหมาย |
|---|---|
| `authLevel` | `1` ตรวจรหัสในเบราว์เซอร์ / `3` ให้ Apps Script ตรวจและแจกกุญแจ |
| `authRequired` | `false` = ไม่ต้องใช้รหัส ใครก็เข้าทำได้ |
| `encrypted` | `true` เมื่อไฟล์ใน `data/` ถูกเข้ารหัสไว้แล้ว |
| `sheetsUrl` / `sheetsKey` | ค่าจากการตั้งค่า Google Sheets |
| `defaultCount` | จำนวนข้อเริ่มต้นในหน้า Setup |
| `secondsPerQuestion` | เวลาต่อข้อ ตั้ง `0` เพื่อปิดการจับเวลา |
| `passMark` | เกณฑ์ผ่านที่ใช้แสดงบนหน้าสรุป |
| `shuffleChoices` | `true` = สลับลำดับตัวเลือกในแต่ละข้อด้วย |
| `defaultLang` | `'en'` \| `'th'` |

## ข้อจำกัดที่ควรรู้

- **เฉลยอยู่ฝั่งเบราว์เซอร์** ใช้ติวได้ดี แต่ห้ามใช้สอบวัดผลจริง
- **ต้องเปิดผ่าน https หรือ localhost** เพราะระบบรหัสใช้ WebCrypto ซึ่งไม่ทำงานบน `file://`
- **ชื่อผู้ทำไม่ได้ยืนยันตัวตน** เมื่อใช้รหัสกลาง ใครพิมพ์ชื่อใครก็ได้ — ถ้าต้องการความแน่นอนให้แจกรหัสรายคน
- **ตัวอ่าน .xlsx** ใช้ `DecompressionStream` ซึ่งมีใน Chrome/Edge 80+, Firefox 113+, Safari 16.4+
  เบราว์เซอร์เก่ากว่านั้นให้ใช้วิธีก๊อปจาก Excel มาวางแทน
- **GitHub Pages แคชแรง** อัปเดตโจทย์แล้วอย่าลืมเปลี่ยน `version` ใน `data/manifest.json`
  ระบบใช้ค่านี้ต่อท้าย URL เพื่อบังคับให้โหลดใหม่
