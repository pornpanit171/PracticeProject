เฉพาะ admin

ต้องใช้รหัส admin

เครื่องมือนี้เห็นเฉลยทั้งคลังพร้อมกัน กรอกรหัส admin เพื่อเข้าใช้งาน

ยังไม่มีรหัส admin? ตั้งได้ด้วย node tools/make-codes.mjs --file admin-codes.json --reset --add "รหัสของคุณ"

เครื่องมือสำหรับเจ้าของระบบ

นำเข้าโจทย์

รับได้ 3 ทาง: ลากไฟล์ .xlsx / .csv มาวาง, ก๊อปข้อมูลจาก Excel มาวางตรง ๆ, หรือวาง JSON ผลลัพธ์คือไฟล์ JSON แยกตามโดเมนพร้อมนำไป commit ลง data/

⬇ ดาวน์โหลดเทมเพลต Excel

1 · ใส่ข้อมูล

ลากไฟล์มาวางที่นี่ หรือคลิกเพื่อเลือกไฟล์ รองรับ .xlsx และ .csv

เลือกช่วงข้อมูลใน Excel รวมแถวหัวตาราง แล้วกด Ctrl+C มาวางในกล่องนี้

วางไฟล์ JSON รูปแบบเดียวกับใน data/ หรือ array ของคำถาม

2 · ตรวจสอบ

3 · พรีวิว

4 · เลือกวิธีรวมกับของเดิม

5 · เผยแพร่

ต้องตั้งค่าเซิร์ฟเวอร์ก่อนถึงจะใช้ปุ่มนี้ได้ — ดูขั้นตอนใน PUBLISH_SETUP.md กดครั้งแรกจะถามหา คีย์เผยแพร่ (คนละอันกับรหัส admin) ระบบจะจำไว้ในเบราว์เซอร์เครื่องนี้ให้

ไม่อยากให้เผยแพร่อัตโนมัติ ดาวน์โหลด/คัดลอกไฟล์ไปวางเข้า repo เองก็ได้ตามปกติที่ด้านล่าง
